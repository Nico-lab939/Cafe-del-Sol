 # Café del Sol ☕🌞

Este es el segundo trabajo práctico de la Diplomatura en Programación Full Stack (UNTREF + Puentes). Consiste en diseñar una landing page para un café ficticio utilizando HTML y CSS, aplicando Flexbox y diseño responsive.
## ✅ Contenido incluido

- **Header** con el nombre del café y navegación.
- **Sección de historia** del café.
- **Sección de productos destacados** (café, medialuna y tostado).
- **Footer** con información de contacto y redes sociales.

## ⚙️ Requisitos técnicos cumplidos

- Uso de **Flexbox** para organizar las secciones.
- Diseño **responsive**, adaptado a celulares y escritorio.
- Paleta de colores coherente con la temática.
- Efectos de transición en los productos al pasar el mouse (hover).
- Estructura de carpetas organizada.
- Control de versiones con Git y publicación en GitHub Pages.
